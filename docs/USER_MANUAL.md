# 📖 AI-Vibe-Trader 사용자 조작 및 운용 매뉴얼 (v2.4.1)

> **시스템 안내:** 본 매뉴얼은 `AI-Vibe-Trader`를 사용하는 일반 사용자를 위한 종합 운용 가이드입니다. 별도의 복잡한 개발 환경 없이 터미널 UI(TUI)를 통해 직관적으로 모든 자율 트레이딩 기능을 제어할 수 있습니다.

---

## 1. 시작하기 (Quick Setup)

### A. 준비 사항
1. **증권사 API 키**:
   * **한국투자증권(KIS)**: [한국투자증권 개발자 센터](https://apiportal.koreainvestment.com/)에서 AppKey 및 AppSecret 발급.
   * **키움증권(Kiwoom)**: [키움증권 Open API 서비스](https://www.kiwoom.com/)를 통해 인증 키 발급 및 계좌 연동.
2. **Google Gemini API 키**: [Google AI Studio](https://aistudio.google.com/)에서 무료/유료 API 키 발급 (AI 시황/종목 분석 필수).
3. **Groq API 키 (선택 사항)**: [Groq Console](https://console.groq.com/)에서 발급 (Gemini 장애 시 초고속 무중단 Fail-over 백업 모델로 사용).
4. **D2Coding 폰트 (필수 권장)**: TUI의 한글 표 및 레이아웃 정렬을 완벽하게 출력하기 위해 동봉된 `fonts/D2Coding.ttf` 글꼴을 터미널에 적용해 주세요.
   * **Windows**: `D2Coding.ttf` 더블 클릭 후 [설치] → Windows Terminal 또는 PowerShell 설정에서 글꼴을 `D2Coding`으로 지정.
   * **Linux**: `/usr/share/fonts/truetype/d2coding` 경로에 복사 후 `fc-cache -fv` 실행.

### B. 첫 실행 및 환경 설정
1. `AI-Vibe-Trader.exe` (또는 Linux 환경에서 `./AI-Vibe-Trader`)를 실행합니다.
2. 최초 실행 시 키보드의 **`S`** 키를 눌러 환경 설정(Config/Setup) 모드로 진입합니다. (모의투자 환경에서는 `K` 키로 자가 진단 가능)
3. 화면의 안내에 따라 필수 정보를 입력합니다:
   * **브로커 선택**: KIS 또는 Kiwoom 선택.
   * **App Key / Secret**: 발급받은 증권사 인증 키.
   * **계좌번호 (CANO)**: 계좌번호 8~10자리.
   * **투자 모드**: 실전투자(N) 또는 모의투자(Y).
   * **AI API 키**: Gemini API Key 및 Groq API Key 입력.
   * **텔레그램 알림**: 스마트폰 알림을 위한 `TELEGRAM_TOKEN` 및 `TELEGRAM_CHAT_ID`.
   * **최대 보유 종목 수 (`MAX_STOCK_COUNT`)**: 동시 보유 한도(1~8). `Y` 입력 시 예수금 규모에 맞춰 AI가 자동 선택.
4. 설정 저장이 완료되면 프로그램이 자동으로 실시간 시세 및 AI 분석 엔진을 가동합니다.

1. **상단 고정 헤더 바 (Header Bar)**:
   * **버전 및 브로커**: 프로그램 버전(`v2.4.1`)과 활성 브로커(`KIS` / `KIW`).
   * **시장 개장 상태**: 국내 정규장(`KR:OPEN/CLOSED`) 및 미국 야간 선물 장세 표시.
   * **시스템 작업 및 피드백**: 현재 백그라운드 워커가 수행 중인 태스크 및 매수/매도 피드백을 노란색으로 강조 표기.
   * **한국 표준시 시계**: KST 기준 요일 및 시/분/초 고정 정렬.
2. **시장 지수 및 VIBE 패널 (Market & Vibe)**:
   * KOSPI, KOSDAQ, 환율 및 비트코인 김치 프리미엄 실시간 표시.
   * **VIBE 상태**: `BULL`, `BEAR`, `NEUTRAL`, `DEFENSIVE` 4대 장세 판정.
   * **DEMA 추세**: `[DEMA: KSP↑ KDQ↓]` 형태로 지수의 20일 이중지수이동평균 대비 상/하회 위치 표시.
3. **전략 파라미터 패널 (Strategy Info)**:
   * `STRAT`: 실시간 Vibe/Phase가 반영된 현재 기본 TP/SL 기준선.
   * `BEAR`: 물타기(하락 방어) 트리거, 회당 금액, 종목 한도, 자동 여부 (🔵 청색).
   * `BULL`: 불타기(수익 확대) 트리거, 회당 금액, 종목 한도, 자동 여부 (🔴 적색).
   * `ALGO`: AI 추천 매매 1회 진입 금액 및 자동 매수/매도 활성화 상태.
4. **보유 종목 포트폴리오 (Portfolio Table)**:
   * 보유 종목의 평가 손익, 실시간 수익률, 동적 TP/SL, 할당된 프리셋 전략명 표시.
   * **수급 시그널**: `[F↑]`(외인 순매수), `[P↑]`(기관/연기금 매집), `[FP↑]`(외인/기관 쌍끌이).
5. **AI 추천 종목 (AI Recommendations)**:
   * Gemini/Groq 및 네이버 퀀트 분석으로 발굴한 주도주 리스트.
   * 자동 진입 허용 범위(당일 등락률 ±8% 이내) 종목은 `[자동]`, 급등주는 추격 매수 방지를 위해 회색 `[수동]`으로 구분.
6. **네이버 실시간 랭킹 (Naver Rankings)**:
   * 검색 상위, 거래량 상위 및 주도 테마 상위 종목 가시화.

## 3. 전체 단축키 및 조작 가이드 (Commands)

| 키 | 기능 명칭 | 설명 |
| :---: | :--- | :--- |
| **`1`** | **수동 매도** | 보유 종목 번호를 선택하여 전량 또는 분할 매도 (시장가/지정가 지원) |
| **`2`** | **수동 매수** | 종목 코드와 수량, 가격을 입력하여 즉시 매수 (20분간 AI 자율 매도로부터 보호) |
| **`3`** | **자동(TP/SL) 설정** | 기본 및 개별 종목의 익절(TP)/손절(SL) 임계치 설정 (`번호 TP SL` 입력) |
| **`4`** | **AI 추천 매매 설정** | 1회 매수 금액 설정 및 AI 자율 매수/매도 자동화(ON/OFF) 전환 |
| **`5`** | **물타기 설정** | 하락장 평단가 관리를 위한 트리거(%), 회당 금액, 한도, 자동 여부 설정 |

| **`7`** | **AI 종목 심층 분석** | 관심 종목 코드를 입력하여 펀더멘털, 뉴스, 재무 지표 기반 AI 진단 리포트 생성 |

| **`D`** | **추천 종목 리포트** | 금일 AI 추천 종목들의 입체적 펀더멘털 분석 상세 리포트 조회 |
| **`H`** | **인기 테마 리포트** | 실시간 인기 검색 TOP 10 및 주도 테마 트렌드 리포트 조회 |

## 4. 리스크 관리 및 방어 메커니즘 (3중 철통 방어 체계)

20거래일 복기 분석(359회 매매)을 통해 밝혀진 **시초가 갭 손실(44.7%), 대형주 몰빵 손실, 그리고 수많은 하위 종목들의 잦은 매매 수수료 누적과 호가 노이즈 휩쏘(계좌 잠식)**를 원천 봉쇄하기 위해 3중 방어 메커니즘이 가동됩니다.

### A. 1차: 복기 기반 5대 손해 축소 핵심 전략
1. **오프닝 갭 가드 (09:00~09:20)**:
   * **신규 매수 동결**: 개장 직후 20분간 AI 자율 매수를 전면 동결하여 시초가 갭하락 노이즈로 인한 뇌동 매매를 차단합니다.
   * **손절선 완화 버퍼**: 09:00~09:15 동안 보유 종목 손절선에 **-1.0%의 완화 버퍼**를 부여하여 일시적 휩쏘에 의한 바닥 손절을 방지합니다.
2. **단일 종목 Hard Cap**:
   * 단일 종목 최대 투자금을 **총자산의 10%** 및 **절대 상한 800만원** 중 작은 값으로 엄격 제한합니다 (`min(총자산*10%, 800만원)`). 특정 종목 쏠림 리스크를 원천 제거합니다.
3. **당일 동일 종목 2회 손절 락 (Daily Blacklist)**:
   * 1회 손절 발생 시 **3시간(180분)** 쿨다운 적용.
   * 당일 동일 종목에서 **2회 손절** 발생 시, 해당 종목은 15:30 장 마감까지 **당일 신규 매수가 전면 금지**됩니다.
4. **수익 보존 트레일링 스탑 (Trailing Stop)**:
   * 당일 수익률이 **+3.0% 이상** 도달한 종목은 최고 수익률을 실시간 추적합니다.
   * 주가가 **최고점 대비 1.0%p 반락**하는 순간 전량 시장가 매도하여 이익을 확정 보존합니다.
5. **Bear/Neutral 역배열 음봉 낙주 필터**:
   * 시장 Vibe가 하락장(Bear) 또는 횡보장(Neutral)일 때, 당일 음봉이거나 20일 이동평균선(20MA) 하단에 위치한 역배열 종목은 자동 매수 대상에서 배제합니다.

### B. 2차: 하위 종목 수수료 누수 방지 및 조기 손절 휩쏘 차단 (v2.4.1)
1. **SL Guard -2.5% 안전마진 강제 확보**:
   * 하락장이나 수렴 구간에서 손절선이 -1.0% 내외로 과도하게 치솟는 것을 방지합니다.
   * 아무리 타이트한 장세라도 **손절선 상한을 최소 -2.5%**로 강제 확보하여, 매수 직후 호가 1~2틱 하락이나 제비용(0.25~0.3%)만으로 기계적 손절이 나가는 문제를 차단합니다.
2. **신규 매수 초기 10분(600초) 호가 노이즈 보호막**:
   * 신규 매수 체결 직후 10분 동안은 마이너스 진입 즉시 털리는 것을 막기 위해 통상적인 SL 손절을 유예합니다 (`🛡️ 매수 직후 초단기 보호`). 단, -7.0% 폭락이나 글로벌 패닉 시에는 즉시 손절합니다.
3. **자투리 1주 매매(Dust Trading) 전면 금지**:
   * 소액 잔고에 의한 1주(2~3만원) 억지 매수를 완전 폐지하고, 1회 최소 주문액 기준(최소 30만원) 미달 시 신규 매수를 건너뛰어 의미 있는 단위의 포지션만 진입합니다.
4. **최소 유동성 거래대금 필터 (30억원 이상)**:
   * 당일 거래대금이 30억원 미만인 소외주는 호가 스프레드 손실 방지를 위해 자동 매수 대상에서 배제합니다.
5. **교체 매매(Replacement) 일일 3회 상한 & 복기 종합 통계 전수 집계**:
   * 하루 최대 종목 교체 매매를 3회로 제한하여 과도한 Churning 수수료를 방지합니다.
   * `trade_retrospective.json`에 당일 총 매매 건수, 총 추정 수수료/세금, 하위 종목 손익을 전수 집계하여 계좌 침식을 100% 투명하게 관리합니다.

### C. 3차: VIBE-GUARD 실시간 미시 방어막
* **시간 지연 손절 유예 (Time-Buffered SL)**: 손절선 이탈 시 즉시 매도하지 않고 60초간 대기하여 반등 기회를 제공합니다.
* **과도매매 가드 (OTG)**: 일일 누적 손절 3회 도달 시 신규 AI 매수를 전면 정지합니다 (`!GUARD(OTG)!`).
* **시초가 지지선 필터**: 09:00~09:30 초반 분봉 20MA 지지가 미달된 종목의 추격 매수를 제한합니다.

## 5. 지능형 물타기 및 불타기 알고리즘

### A. 물타기 (Recovery Engine - 하락 방어) — `5` 키
* **트리거 조건**: 수익률이 **현재 실시간 손절선(SL) + 1.0% 이상** 구간 & 현재가 < 매입평단.
* **추가 진입 조건**: 직전 매수가 대비 **-2.0% 이상 추가 하락** 시에만 집행.
* **집행 후 안전망**: 물타기 체결 직후 **30분간 손절 유예** (단, SL -1.0% 추가 하락, 패닉, 방어모드 시 즉시 손절).
* **현금 비중 체크**: 하락장(Bear) 가용 현금 30% 이상, 방어모드(Defensive) 80% 이상 필수.

### B. 불타기 (Pyramiding Engine - 수익 확대) — `6` 키
* **트리거 조건**: 수익률이 설정값 이상 & 현재가 > 매입평단.
* **충돌 방지 로직**: 불타기 트리거는 항상 **실시간 익절선(TP) - 1.0% 이하**로 자동 제한하여 매수 직후 익절되는 핑퐁 매매 차단.
* **추가 진입 조건**: 직전 매수가 대비 **+2.0% 이상 추가 상승** 시 집행 (상승장 또는 거래량 폭발 시에만 가동).
* **쿨다운 자동 리셋**: 불타기 체결 시 기존 부분 익절 쿨다운이 즉시 리셋되어 새 포지션에서 즉시 익절 추종 가능.

## 7. 텔레그램 원격 제어 및 알림 (Telegram Control)

스마트폰 텔레그램 봇을 통해 언제 어디서나 시스템 상태를 확인하고 긴급 제어할 수 있습니다.

### A. 실시간 알림
* **매매 체결**: 매수, 매도, 익절, 손절, 트레일링 스탑 체결 즉시 실시간 알림 발송.
* **정기 리포트**: 09:00 장 시작 시황, 15:30 장 마감 손익 요약, 16:00 성과 복기 리포트 발송.
* **긴급 경보**: 글로벌 패닉 감지, 서킷 브레이커 발동 시 즉각 비상 메시지 전송.

### B. 텔레그램 원격 제어 명령어
* `/status` : 현재 총자산, 가용 예수금, 당일 손익률, 시장 VIBE 상태 조회.
* `/buy [종목코드] [수량] [가격]` : 원격 수동 매수 (가격 생략 시 시장가 주문). 예) `/buy 005930 10`
* `/sell [종목코드] [수량] [가격]` : 원격 수동 매도 (가격 생략 시 시장가 주문). 예) `/sell 005930 10`
* `/panic` : **비상 패닉 발동**. 모든 신규 매수를 즉시 동결하고 보유 전 종목 시장가 긴급 청산.
* `/pause` : 신규 매수 일시 정지 (기존 보유 종목의 익절/손절 관리는 계속 유지).
* `/resume` : 일시 정지 상태를 해제하고 자율 트레이딩 정상 재개.
* `/defensive` : AI 판단과 무관하게 시스템을 극보수적 방어모드로 강제 전환.
* `/reset` : 패닉, 일시정지, 강제 방어모드 등 모든 수동 개입 상태를 일괄 해제하고 AI 자율 모드로 복귀.

## 8. 문제 해결 및 자주 묻는 질문 (FAQ)

* **Q: 데이터가 갱신되지 않거나 '데이터 없음'이 뜹니다.**
  * A: 인터넷 연결 상태를 확인하고, `S:셋업` 메뉴에서 증권사 API Key 및 계좌번호가 유효한지 확인하세요. KIS API의 경우 주기적으로 토큰이 자동 갱신됩니다.
* **Q: AI 분석(7/8번) 시 오류가 발생합니다.**
  * A: Google AI Studio에서 발급받은 `GEMINI_API_KEY`가 정확한지 확인하세요. Groq API 키를 함께 등록해 두면 Gemini 일시 장애 시 Groq으로 자동 무중단 Fail-over 됩니다.
* **Q: 폰트가 깨지거나 터미널 줄이 어긋납니다.**
  * A: 터미널 에뮬레이터(Windows Terminal, PowerShell 등) 설정에서 글꼴을 반드시 **`D2Coding`**으로 변경해 주세요.
* **Q: 실행 파일(.exe) 실행 시 보안 경고가 뜹니다.**
  * A: 개인 개발 바이너리에 디지털 서명이 없는 경우 윈도우 SmartScreen 경고가 뜰 수 있습니다. [추가 정보]를 클릭한 후 [실행]을 선택하시면 정상 구동됩니다.
